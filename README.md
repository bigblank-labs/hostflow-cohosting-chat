# Hostflow — Cohosting Chat

Public landing + chat interface for Hostflow digital products.

Hosted at: https://bigblank-labs.github.io/hostflow-cohosting-chat/

## What's deployed

- One-page chat interface (index.html, ~22KB self-contained)
- 2-minute intake recommends Cohosting Starter Kit ($200) or Mentorship ($1,000)
- Hostflow brand tokens (navy #0B1220, blue #3D5AFE, Inter)
- Stripe Payment Link CTAs — pending Josh's Stripe account setup

## How to update

1. Edit `index.html` in this repo
2. Push to `main` branch
3. GH Pages will republish within ~60 seconds

To replace Stripe placeholders: search for `__STRIPE_STARTER_PENDING__` and
`__STRIPE_MENTOR_PENDING__` in `index.html` and paste your real Stripe
Payment Links.
